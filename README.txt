SPAREBLIKK – GRATIS SPARE- OG BUDSJETTAPP

Denne mappen er en ferdig liten nettside som kan installeres på iPhone som
om den var en app. Den er privat, gratis og trenger ikke banktilkobling.

SLIK FÅR DU DEN PÅ IPHONE – GITHUB PAGES (GRATIS):
1. Lag en gratis konto på github.com hvis du ikke har det.
2. Opprett et nytt offentlig repository, f.eks. 'spareblikk'.
3. Last opp ALLE filene i denne mappen til toppnivået i repositoriet.
   (Ikke last opp ZIP-filen som én fil.)
4. Gå til Settings > Pages i repositoriet.
5. Velg Deploy from a branch, branch 'main', mappe '/ (root)' og Save.
6. GitHub viser etter publisering en nettadresse som normalt ligner:
   https://DITT-BRUKERNAVN.github.io/spareblikk/
7. Åpne adressen i Safari på iPhone, trykk Del og velg
   «Legg til på Hjem-skjermen». Velg «Åpne som nettapp» hvis valget vises.
8. Åpne appen fra det nye ikonet på Hjem-skjermen.

FÅ TESTET APPEN PÅ DATAMASKIN:
Åpne index.html i en nettleser. Appen virker normalt direkte i nettleseren,
men hjemskjerminstallasjon og offlinefunksjoner krever HTTPS-adresse.

DET KAN DU GJØRE:
- Se ukebudsjett og hvor mye du har brukt fra mandag til søndag.
- Legge til, endre og slette kjøp med kategori og dato.
- Se historikk og kategorier.
- Registrere faktisk sparing fra ukelønn og barnetrygd.
- Endre inntekt og sparemål i Innstillinger.
- Ta sikkerhetskopi / gjenopprette fra en JSON-fil.

VIKTIG OM DATA:
Data lagres i nettleseren/på telefonen, ikke på GitHub og ikke i banken.
Det er ingen automatisk synkronisering mellom enheter. Bytte av nettleser,
bytte av enhet, sletting av nettsteddata eller enkelte iOS-oppryddinger kan
fjerne lokal lagring. Ta sikkerhetskopier under Innstillinger med jevne mellomrom.
En offentlig GitHub Pages-side viser KODEN, men IKKE kjøpene eller sparebeløpene
som lagres lokalt på telefonen.

Ukebudsjettet er beregnet fra ukelønn minus sparing fra ukelønn. Eventuelt
forbrukbart restbeløp av barnetrygd er IKKE regnet med, fordi totalbeløpet er
ukjent. Juster derfor budsjettet om du bruker andre penger i tillegg.
